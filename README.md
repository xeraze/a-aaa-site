# A AAA Site

### An intentionally simple infinite “A” experiment

A tiny browser experiment built around a single idea: continuously writing the letter `a` on the page.

## Overview

**A-A-A Site** is a deliberately minimal web experiment. The entire project is centered around rendering the letter `a` continuously in the browser.

The implementation is intentionally tiny, with the complete experience contained in a single HTML page.

## Tech Stack

- HTML5
- CSS / browser rendering
- Vanilla JavaScript, where required by the page
